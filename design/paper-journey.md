# 撕纸人物与连续滚动叙事

## 方向

本方案替代首页右侧的抽象线条曲面，围绕人物重新编排首屏与章节布局，保留双语事实内容、原站白色 / 炭灰底色以及蓝色 / 金黄品牌变量。参考调研沿用 [kinetic-home.md](./kinetic-home.md) 中记录的 ThreeUI、Codrops 和 Sketchbook；本轮人物、拼贴绘制和滚动逻辑为原创实现，没有复制参考站素材或组件。

人物按用户追加要求重做：保留黄帽、圆眼镜、蓝卫衣的辨识点，采用更利落的成人脸型和修长比例，配合水彩质感、不规则米白撕纸边、纸纤维与薄纸阴影。没有使用此前被否定的圆润卡通人物。

## 素材

- 使用内置 image generation 工具生成，原头像为 `docs/public/ava.png`。
- 六张 2×2 动作图保存在 `https://oss.justin3go.com/paper-journey/paper-journey/`：`intro.png`、`code.png`、`photo.png`、`badminton.png`、`walk.png`、`chat.png`，共 24 个姿态。
- 完整生成提示词与源图文件名见 [paper-journey-prompts.json](./paper-journey-prompts.json)。第一张确定人物造型，其余四张使用它保持人物和撕纸风格一致。
- 原有五张动作图是带洋红底色的 RGB PNG；新增开场 `intro.png` 是原生透明 RGBA，保持生成结果不变。原图完整保留，页面加载时在 Canvas 中一次性去色、消除边缘溢色、检测四帧边界，并按统一比例与脚底位置注册成透明图集。动画过程中只绘制缓存图集，不重复读取像素。
- 羽毛球左下帧球拍跨过标准中线，使用自定义区域完整包含球拍。无需修改源图。
- 包含开场的六张原图合计约 9.4 MiB；先加载当前场景，再提前加载相邻场景，没有把全部图片作为首屏关键资源。资源失败时回退到原头像，正文和链接不受影响。

## 连续镜头

| 页面内容 | 人物动作 | 转场与配景 |
| --- | --- | --- |
| 首屏（右侧） | 自然站立、转头、挥手 | 独立欢迎肖像，无电脑、相机等道具；小幅鼠标响应与慢节奏动作 |
| 作品（左侧） | 坐着写代码 | 开场纸片重组为写代码的人物，全程保持首屏尺寸；代码纸片伴随 |
| 关于、摄影（右侧） | 拿起相机、对焦、放下 | 代码纸片散开，重组为摄影姿态；相片与取景框出现 |
| 羽毛球独立场景（左侧） | 准备、挥拍、收拍 | 摄影姿态分为六片，再组成羽毛球姿态；羽球沿弧线移动 |
| 经历（右侧） | 四帧行走 | 步态由滚动位置决定，可以停下或倒放；虚线路径随之推进 |
| 联系（左侧） | 聆听、手势、挥手 | 人物转向访客，聊天纸片和最终章节说明出现 |

桌面首页共用一个固定 Canvas，在六个真实章节占位之间左右交替移动，使用首屏的实际宽度，最大 560px，不再缩进侧栏。人物在正文旁的视口中部停留；章节边界预留转场空间，让六片带锯齿切口的纸片在文字之间位移、旋转和重组。场景与位置共用同一条可逆 smoothstep 时间线，转场窗口为画布宽度的 1.65 倍、最大 940px。页面使用原生滚动，不劫持滚轮或强制吸附。

鼠标在页面左右移动会选择摄影、羽毛球、聊天的不同姿态，并产生轻微位移。无鼠标时用约 2.6 秒一轮的定格动作；代码有独立打字循环；行走由滚动驱动。页面隐藏时停止 RAF，卸载清理事件与观察器。系统减少动态效果时显示静态姿态，取消连续镜头和纸片过渡。页面不再提供手动暂停按钮。

## 适配

- 860px 及以上：人物与正文各占接近半页，页面最大宽沿用 VitePress 导航的 `calc(var(--vp-layout-max-width) - 64px)`，当前为 1376px；人物与首屏等大，在作品左、摄影右、羽毛球左、经历右、联系左切换。
- 860px 以下：人物只出现在首屏，跟随首屏自然滚出，然后隐藏并停止连续绘制，不保留顶部人物条或后续占位，也不预载后续场景。
- 首屏采用两块撕边标题纸、横线便签、胶带、印章和手绘箭头；项目是带胶带的小明信片，摄影是相片拼贴，羽毛球是球场便签，联系是信纸。新增配景为原创 CSS / SVG，沿用已认可的人物素材。
- 页面内章节链接使用与动画终点一致的滚动间距（人物视口纵坐标减章节上边距）；初次深链接和浏览器历史跳转在 VitePress 默认滚动之后对齐，保证进入章节时人物已重组完成、标题位于导航下方。修饰键打开新标签的行为保留。
- 图形配景从现有主题变量读取颜色，人物自身保留自然颜色和米白纸边。
